# Ethics & scope

This is a personal project for defensive security
research. It studies **code-reuse patterns across phishing kits**
using similarity techniques (fuzzy hashing, clustering).

## What this project does NOT do

- Does not download, host, or distribute real phishing kits.
- Does not interact with live or compromised third-party infrastructure.
- Does not collect any real victim data.
- Does not implement working credential-collection/exfiltration
  logic. The "backend" files (`config.php.txt`, `process.php.txt`,
  `antibot/check.php.txt`) are inert placeholders — `.txt`, not
  executable, with no real endpoint. Any "obfuscated-looking" blob is
  a base64-encoded disclaimer that decodes to plain text saying it is
  synthetic; it is never real or functional obfuscated code.
- Does not impersonate real brands: every kit theme, including
  `rebrand` variants generated by the mutation engine, is fictional
  (`NimbusBox`, `Northwind Bank`, `Zephyr Mail`, `Meridian Trust`,
  etc.).
- Does not use real domains — only `example.invalid`, reserved by
  [RFC 2606](https://www.rfc-editor.org/rfc/rfc2606) for documentation
  and testing, guaranteed to never resolve.
- Does not implement real visitor-filtering,  anti-bot or cloaking
  logic. The `antibot/` folder and `.htaccess` in `family_beta` only
  mark that this layer commonly exists in real kits, but they contain
  no working detection-evasion code, IP ranges, or user-agent lists.

## Why synthetic data

A synthetic, labeled dataset lets me practice and validate the exact
same techniques (fuzzy hashing, feature extraction, clustering) that
would be used on real data, without the legal/ethical risk of touching
third-party compromised infrastructure or real victims' data.

## If real data is ever added later

Any future extension using real kits (e.g. from an academic dataset
with a clear license) would happen in a separate, private stage, with
full sanitization first — removing live endpoints, credentials, and
brand/logo references — before publishing anything beyond aggregated
hashes, features, and metrics.
